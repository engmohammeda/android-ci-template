# CI Template — قالب أتمتة إنتاجي لتطبيقات أندرويد

هذا المستودع قالب جاهز يمنح أي تطبيق أندرويد خط إنتاج كاملاً منذ اللحظة الأولى:

- **بناء تلقائي** لنسخ Debug وRelease وAAB عند كل دفعة إلى الفرع الرئيسي.
- **بوابة اختبارات إلزامية** تمنع وصول أي كود مكسور إلى الإصدارات.
- **ترقيم دلالي (SemVer) تلقائي** يُحسب من رسائل الـ commits (feat → minor، غيرها → patch).
- **ملاحظات إصدار مصنّفة** (أُضيف/أُصلح/تغيّر/داخلي) تُولَّد تلقائياً.
- **إصدارات GitHub Releases** مع بصمات SHA256 وأحجام الملفات.
- **إرسال تلقائي إلى تلجرام**: رسالة الملاحظات + ملفات APK وAAB.
- **صفحة خصوصية ووصف** تُنشر على GitHub Pages برابط ثابت صالح لمتجر Play.
- **فحص جاهزية المتجر (store-lint)**: أطوال الأوصاف، اللقطات، الرسم الترويجي، الأيقونات.
- **رفع اختياري إلى Google Play** (مسار internal) عبر حساب خدمة.
- **بناء أسبوعي (bitrot)** يكشف تقادم الفرع الرئيسي مبكراً.

استبدل التطبيق النموذجي بتطبيقك، واحتفظ بخط الأتمتة كما هو.
